# BYT Calculator with Unit Testing (NUnit)

A simple C# console application that performs basic arithmetic operations.

Calculator Features
- Addition
- Subtraction
- Multiplication
- Division

## Project Usage
1. Open the solution in Visual Studio or Rider
2. Build the project
3. If you want to see how calculator works, uncomment Program.cs and run it to see console output demonstrating calculation result. Otherwise, go to step 4
4. Run tests to see different tests from simple ones (whether addition or multiplication results are correct) to much more complex (like whether division can give result with floating point or whether it is possible to divide by zero)
